# আড়াইহাজার মারকাজ পোর্টাল (এডমিন + ইউজার) — Firestore সংস্করণ

## ফাইল
| ফাইল | কাজ |
|---|---|
| `index.html` | ইউজার পোর্টাল |
| `admin.html` | এডমিন পোর্টাল |
| `app.js`, `style.css`, `firebase-config.js` | দুই পোর্টালের শেয়ার্ড কোড (তাই দেখতে একই রকম) |
| `firestore.rules` | Firestore সিকিউরিটি রুলস |

## একবারের সেটআপ (Firebase Console → project: markaz-6761d)
1. **Authentication → Sign-in method** → *Email/Password* চালু করুন।
2. **Firestore Database** → *Create database* (production mode)। তারপর **Rules** ট্যাবে `firestore.rules` এর লেখা পেস্ট করে Publish করুন।
3. **প্রথম এডমিন বানান:**
   - Authentication → Users → *Add user*: ইমেইল `admin@markaz.app`, একটি শক্ত পাসওয়ার্ড দিন।
   - তৈরি হওয়া ইউজারের **User UID** কপি করুন।
   - Firestore Database-এ *Start collection* → Collection ID: `admins` → Document ID: সেই `<UID>` → একটি ফিল্ড দিন (যেমন `role` = `admin`) → Save।
4. ফাইলগুলো একই ফোল্ডারে রেখে Firebase Hosting (বা যেকোনো হোস্টিং) এ আপলোড করুন। অন্য ডোমেইনে হোস্ট করলে Authentication → Settings → *Authorized domains* এ সেই ডোমেইন যোগ করুন।

## ডাটা কাঠামো (collections)
`admins`, `users`, `members`, `positionRequests`, `jamats`, `notices` — সবকিছু অ্যাপ নিজে তৈরি করে, হাতে বানাতে হবে শুধু `admins` এর প্রথম ডকুমেন্ট।

## ব্যবহার
- `admin.html` এ `admin` / পাসওয়ার্ড দিয়ে ঢুকে **ইউজার আইডি ম্যানেজমেন্ট** থেকে ১২ এলাকার জন্য আইডি বানান।
- ইউজার `index.html` এ নিজের আইডি দিয়ে ঢোকে। শুধু নিজ এলাকার জন্য মেম্বার/পজিশন/জামাত আবেদন করতে পারে।

## কীভাবে চলে
- **অ্যাড মেম্বার** → `অপেক্ষমান` → এডমিন অনুমোদন দিলে "সব মেম্বার" তালিকায় আসে।
- **পজিশন রিকুয়েস্ট** → এডমিন অনুমোদন দিলে মেম্বারের পজিশন আপডেট হয়।
- **জামাত আবেদন (নিজ/আউটসাইড)** → এডমিন "সম্পাদনা" থেকে সাথী যোগ/মুছা, মসজিদ নির্ধারণ করে "অনুমোদন" দিলে ড্যাশবোর্ডের **RUNNING INTERNAL / OUTSIDE JAMAT** এ দেখায়। "সমাপ্ত" করলে তালিকা থেকে সরে যায়।
- **নোটিস বোর্ড** শুধু এডমিন দিতে/মুছতে পারে।

## সীমাবদ্ধতা (জেনে রাখুন)
- ইউজার আইডি আসলে `আইডি@markaz.app` ইমেইল হিসেবে Firebase-এ থাকে (আসল ইমেইল লাগে না)।
- ব্রাউজার থেকে Firebase Auth ইউজার ডিলিট বা অন্যের পাসওয়ার্ড রিসেট করা যায় না। তাই এডমিন ইউজারকে **বন্ধ/চালু** করতে পারে; বন্ধ করা ইউজার আর ডাটা পড়তে পারে না। পাসওয়ার্ড ভুলে গেলে নতুন আইডি বানান বা Firebase Console থেকে রিসেট করুন।
- ইউজার নিজের পাসওয়ার্ড প্রোফাইল পেইজ থেকে বদলাতে পারে (কিছুক্ষণ আগে লগইন না থাকলে আবার লগইন করতে বলবে)।
